About HCK Labs

One person. Multiple builds.

HCK Labs is a label for projects built by Marcin "HCK" Firmuga. No team page. No fake headcount. The work is the point: write it, test it, break it, fix it, ship it, then show what changed.

Public by default Code, releases and development notes stay visible while the projects change.
Evidence over polish Tests, real screenshots and shipped builds matter more than a perfect pitch deck.
Small enough to change No committee needed. If an idea is weak, it gets rebuilt or removed.
