Roadmap

This is the working state of Scaling Laws, not a promise list. No 82% progress bars. A feature moves from foundation to playable, polish and finally shipped only when the label actually means something.

The 101% rule
SHIPPED means we stop making excuses for it.

A feature is SHIPPED only when it is complete, stable and no longer needs a roadmap disclaimer.
