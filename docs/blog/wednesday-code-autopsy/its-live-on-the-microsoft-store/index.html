It Is Live on the Microsoft Store

One year. One Store listing that 12 months ago was pure fantasy.

By Marcin Firmuga·2026-07-01·3 min read·Wednesday Code Autopsy #15

It is live on the Microsoft Store.

A year ago that sentence was the last line of a roadmap I wrote but did not believe I would reach. 12 dead projects behind me. A 2014 laptop that hits 94 degrees. Code written after welding shifts, at 3am, on energy drinks and toast.

A week ago I posted "Microsoft said no." Blurry icon, wrong privacy link. Today Microsoft said yes.

PC Workman, a Windows system monitor with a fully offline AI, built solo and in public, is now permanently on the Microsoft Store. No more "download a random zip." Just click Install.

To everyone who tested it, broke it, starred it, or dropped a question that became a feature: this one is yours too.

Fear of "is this safe? where is my data going?" ends today. But the obsession with your security and privacy does not. That stays in every line, forever.

One year. One Store listing that 12 months ago was pure fantasy. Still shipping.
