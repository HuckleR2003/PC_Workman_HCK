Twórca i opiekun PC Workmana. Jedna osoba, publiczne repozytorium, sprawdzalne wydania.

Buduję PC Workmana, otwartoźródłowy monitor Windows, który wyjaśnia bieżące dane, uczy się normy konkretnej maszyny dla różnych obciążeń i zawiera lokalnego asystenta hck_GPT.

Projekt zaczął się po zmianach magazynowych w Holandii. Pierwsza wersja miała pomóc zrozumieć, dlaczego stary laptop przegrzewał się i obniżał taktowanie. Dziś program jest dostępny przez Microsoft Store, GitHub i SourceForge. Kod, historia zmian, testy oraz polityka bezpieczeństwa pozostają publiczne.
