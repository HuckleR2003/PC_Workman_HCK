My Assistant Is Not Allowed to Guess Whether That CPU Fits Your Board

It is not another chatbot inside a system monitor. It is a local technician that can show its work.

By Marcin Firmuga·2026-07-13·4 min read·Monday Grind Blueprint #16

Most AI assistants are trained to sound useful. Mine is not allowed to guess whether your motherboard supports the CPU you want to buy.

Before hck_GPT can answer "Will this CPU work with my current board?" or "Is this old GPU driver safe to remove?", every part of PC Workman has to agree on what machine it is looking at. Right now My PC, sensor monitoring, learning engines and hck_GPT still reach parts of the same data through different paths.

It works, but it makes bugs harder to catch, results harder to explain, and the whole system harder to trust.

So this week starts with one job: one collector, shared hardware state, and clearer data across My PC, voltage and usage monitoring, learning, and hck_GPT.

Then four new roadmap issues, built from real power-user feedback

  • Hardware Upgrade Compatibility Check: CPU, motherboard, RAM, GPU and upgrade preparation.
  • Local Hardware Compatibility Library: 200+ structured entries. Offline. No web search required.
  • Windows Repair Command Advisor: DISM, SFC, Store failures, unknown devices and Event Viewer, explained before anything is touched.
  • Driver Store Cleanup Advisor: read existing PC Workman scans, find likely leftovers, explain the risk and build a safe checklist. No random PowerShell.
No "100% compatible" when important data is missing, and no pretending a confident answer is the same as a correct one.

The goal is not another chatbot inside a system monitor. It is a local technician that can show its work.
