Sterowniki, które chowa Menedżer urządzeń, i te, które trzeba zaktualizować

Każda mysz, słuchawki i pendrive, które kiedyś podłączyłeś, zostawiają sterownik. Konfiguracja i sterowniki znajduje te duchy, ocenia wiek sterowników, których naprawdę używasz, i wskazuje bezpieczną drogę aktualizacji każdego, bez wciskania aktualizatora sterowników.

Sterowniki-duchy

Windows trzyma sterownik każdego urządzenia, które kiedykolwiek było podłączone. Menedżer urządzeń je chowa, dopóki nie włączysz „Pokaż ukryte urządzenia”. Większość jest niegroźna, ale stare duchy dźwięku i sieci potrafią mylić, które urządzenie wybiera Windows, a długa lista spowalnia szukanie sterowników. Na moim komputerze: 7 duchów mikrofonu Steam Streaming, 3 karty sieciowej, 4 kontrolera USB.

Konfiguracja i sterowniki grupuje duchy według urządzenia, mówi, czym była każda grupa, i jednym kliknięciem otwiera Menedżer urządzeń; tam Widok › Pokaż ukryte urządzenia je wypisuje, a Ty usuwasz to, co wybierzesz, tam, gdzie Windows tego oczekuje.

Wiek sterowników, oceniony spokojnie

Sterownik kontrolera USB z 2017 roku jest w porządku; sterownik karty graficznej sprzed dwóch lat w nowej grze już nie. Strona ocenia wiek według klasy urządzenia zamiast krzyczeć „przestarzały” przy wszystkim i mówi, gdzie aktualizować: Windows Update dla większości urządzeń, NVIDIA App albo AMD Adrenalin dla grafiki.

Gotowość na pierwszy rzut oka

Nagłówek pokazuje wersję i kompilację Windows, czas pracy, ostatni start i wynik gotowości z liczbą aktualnych sterowników. Szybkie akcje otwierają Windows Update, Menedżer urządzeń, Usługi, Harmonogram zadań, Informacje o systemie i MSConfig.

Pytania

Czym są sterowniki-duchy?

To sterowniki urządzeń, które nie są już podłączone: starych myszy, słuchawek, pendrive'ów, poprzedniej karty graficznej. Windows je trzyma; Menedżer urządzeń pokazuje je tylko z opcją Pokaż ukryte urządzenia.

Czy usuwanie sterowników-duchów jest bezpieczne?

Zwykle tak dla urządzeń, których już nie podłączysz. Jeśli podłączysz, Windows zainstaluje sterownik ponownie. Zostaw wszystko, czego nie jesteś pewien.

Czy używać aktualizatora sterowników?

Nie. Używaj Windows Update dla większości urządzeń i aplikacji producenta dla karty graficznej. Zewnętrzne aktualizatory czasem instalują zły sterownik i często coś sprzedają.
