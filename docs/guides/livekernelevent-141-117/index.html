LiveKernelEvent 141 and 117: your graphics card hung, and Windows survived it

Reliability Monitor calls it a hardware error. It is a record of a graphics hang Windows recovered from, with a dump that says more.

By Marcin Firmuga·Published 2026-11-27·9 min read
Short answer

LiveKernelEvent 141 and 117 mean the graphics card stopped responding for a moment and Windows recovered instead of crashing. The screen usually goes black or the game freezes, then things come back, or the game closes. One event after a driver install is noise. Several a week during games are a pattern worth finding.

  1. Note when it happens: which game, how often, since which date.
  2. Return every overclock and undervolt to defaults: graphics card, CPU, and XMP or EXPO for a test.
  3. Do a clean install of the graphics driver.
  4. Check graphics card temperature and power under load.
  5. Only if it continues at defaults with a clean driver, suspect the card itself.

What each code means

LiveKernelEvent is not one error. It is the name Windows Error Reporting gives to a live kernel dump: Windows noticed something wrong, saved a snapshot of memory for diagnosis, and kept running. The number after it tells you what was wrong. Microsoft's live dump reference lists these graphics codes:

CodeMicrosoft nameWhat it means
117VIDEO_TDR_TIMEOUT_DETECTEDThe display driver failed to respond in time and was reset (Timeout Detection and Recovery).
141VIDEO_ENGINE_TIMEOUT_DETECTEDOne of the graphics card's engines failed to respond in time.
193VIDEO_DXGKRNL_LIVEDUMPThe Windows graphics kernel captured a dump about a problem it detected.
1A8VIDEO_DXGKRNL_BLACK_SCREEN_LIVEDUMPThe graphics kernel recorded a black screen.
1B8VIDEO_MINIPORT_BLACK_SCREEN_LIVEDUMPThe graphics driver (the miniport) recorded a black screen.

Microsoft notes that these codes are never used for a real blue screen. They exist only to label live dumps. That is the important part: your PC did not crash. The graphics stack hung, Windows reset it, and wrote down what it saw. On NVIDIA cards the same moment usually also leaves nvlddmkm Event 153 or Display 4101 in Event Viewer; on AMD cards it often comes with the AMD driver timeout message.

Where you see it, and the dump it leaves

  • Reliability Monitor: press Win + R, type perfmon /rel. A red cross marked Hardware error, and in the details Problem Event Name: LiveKernelEvent with Code: 141 (or 117, 1a8…).
  • The dump files: Windows stores live dumps in C:\Windows\LiveKernelReports, with small dumps in subfolders per component. Graphics hangs land in WATCHDOG. Advanced users can open a .dmp in WinDbg and run !analyze -v; it names the driver module that hung.
  • Event Viewer at the same minute: Display 4101, nvlddmkm 153, or an AMD driver entry. Matching the time is how you know they belong together.

How often is too often

  • Once, right after a driver install or a Windows update: common, and usually nothing to chase.
  • A few times a month, always in the same game: often that game, its settings or its overlay. Try it without overlays and at default graphics settings.
  • Several a week, across different games, or at idle on the desktop: a system cause. Work through the order below.
  • Followed by full restarts: also read Kernel-Power 41, because the hang then became a crash.

A safe order to find the cause

Change one thing at a time and play the same game for the same time after each change. Otherwise you will not know which step helped.

  1. Defaults first. Reset any graphics card overclock, undervolt or custom fan curve in Afterburner, Adrenalin or the maker's tool. For the test, also turn off XMP or EXPO in the BIOS. Unstable tuning is the most common cause of graphics hangs that look like hardware faults.
  2. Clean driver install. Remove the graphics driver completely (the vendor's clean-install option, or AMD Cleanup Utility; DDU in Safe Mode for stubborn cases), then install the current version from NVIDIA, AMD or Intel. If the events started after a driver update, try the previous version.
  3. Heat and power under load. Watch the graphics card temperature, hotspot and power while gaming. A card that hangs only after twenty minutes of load points at cooling. Use separate power cables from the power supply to each PCIe connector rather than one split cable.
  4. Memory. Run Windows Memory Diagnostic or a longer memory test. Unstable RAM can take the graphics driver down with it (see XMP and EXPO crashes).
  5. Software that hooks into games. Recording tools, overlays and RGB utilities: turn them off one at a time.
  6. The card itself. If the hangs continue at defaults, with a clean driver, normal temperatures and stable memory, test the card in another PC or another card in yours. If the problem follows the card, contact the seller about warranty.

What not to do

  • Do not raise TdrDelay as the fix. It is the timeout Windows waits before resetting the driver (2 seconds by default). Raising it hides the reset and leaves the hang; Microsoft documents it as a debugging key. More in the nvlddmkm guide.
  • Do not buy a "repair" tool. Several pages that rank for this error sell one. The cause is in the order above, and every step is free.
  • Do not delete the dumps to make it go away. They are copies for diagnosis and can be large; deleting old ones frees space and changes nothing about the cause.

Short answers

What is LiveKernelEvent 141?

Code 141 is VIDEO_ENGINE_TIMEOUT_DETECTED: one of the graphics card's engines stopped responding in time. Windows recovered without a blue screen and saved a diagnostic dump.

What is the difference between 117 and 141?

117 means the display driver failed to respond and was reset; 141 means one display engine of the card failed to respond. Both are graphics hangs Windows survived, and the same steps apply.

What are LiveKernelEvent 1A8 and 1B8?

Black screen live dumps: 1A8 from the Windows graphics kernel, 1B8 from the graphics driver. Windows recorded a black screen and captured a dump.

Is it a hardware error?

Reliability Monitor files it that way, but the cause is often the driver, tuning, heat or power. Suspect the card only after the defaults and clean driver steps.

Can I delete the LiveKernelReports folder?

The files are diagnostic copies. Deleting old ones frees space; it does not change the cause.
