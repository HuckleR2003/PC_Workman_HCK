How much RAM do you need in 2027? Measure before you buy expensive memory

Memory got expensive when AI data centres took the supply. That makes the old advice, "just get more", the most expensive guess you can make.

By Marcin Firmuga·Published 2026-11-27·8 min read
Short answer

Buy RAM when your own PC shows it is short, not because the percentage looks high. Run your heaviest normal session (the game, the browser, chat, whatever you really keep open) and check three numbers:

  1. Committed memory in Task Manager goes above your installed RAM.
  2. Hard faults per second in Resource Monitor jump when it stutters.
  3. RAM stays above ~90% through the session, not only for a moment.

All three: more RAM will help. None: it will not, and the money is better spent elsewhere. As a rough guide for 2026–2027: 8 GB is tight for modern games, 16 GB covers most gaming, 32 GB is for streaming, heavy multitasking and local AI.

Why measuring matters more now

Memory makers moved capacity to the memory AI data centres buy, and the rest of the market pays for it. In early 2026 TrendForce revised its forecast to DRAM contract prices rising 90–95% in a single quarter. By the second half of the year Tom's Hardware reported the surge starting to cool as buyers hit their limit, while prices kept climbing through the third quarter. Analysts disagree on how long it lasts, but none of them describes a quick return to cheap memory.

When a RAM upgrade was cheap, buying it "just in case" cost little. Now it can cost as much as a graphics card upgrade. So the question is no longer "how much RAM is good", but "is my PC actually short of memory".

The percentage is not the signal

Windows fills free memory with cache and hands it back the moment a program asks. Windows Latest, testing 4, 8 and 16 GB PCs in November 2026, quoted Microsoft's point that using most of the RAM is fine and that the real test is whether the PC stays responsive. A Task Manager showing 80% at the desktop is normal. More on that in why RAM usage looks so high.

Three numbers that are

  1. Committed (Task Manager, Performance, Memory). It reads like 12.4/14.8 GB: memory programs have asked for, out of what RAM plus the page file can give. When the first number goes above your installed RAM during normal use, Windows is relying on the disk to hold the overflow.
  2. Hard faults per second (Resource Monitor, resmon, Memory tab). A hard fault means Windows had to read a page from disk because it was not in RAM. A few are normal. Hundreds or thousands exactly when the game stutters means memory ran out.
  3. How long RAM stays high. A spike to 95% while a game loads is fine. Sitting above about 90% for the whole session, with the two numbers above, is a shortage.

Measure during the session you actually have, with everything you really keep open. A clean desktop with only the game running tells you about a PC you do not use.

A real example: 8 GB in a modern game

On my own 8 GB PC, PC Workman recorded several sessions of 7 Days to Die: RAM averaged 86–89% and peaked at 97%, while the graphics card averaged around 60%. Over the same days it learned that this PC normally sits at 79% RAM and stays below 89% for 95% of the time.

That is the pattern of a memory-bound PC: the graphics card has room to spare, and the game is waiting on memory. A faster graphics card would change little there. 16 GB would remove the limit. On a PC where the same game ran at 60% RAM and 99% GPU, the answer would be the opposite.

If you need more: buying well when it is expensive

  • Match the platform. DDR4 and DDR5 are not interchangeable, and boards have limits on speed and size. Check what your board takes before you buy (PC Workman's Upgrade Readiness reads it for you).
  • Two sticks, not one. Dual channel matters for games. Two matched sticks usually beat one larger stick.
  • Adding to what you have is a gamble. A second kit of the "same" RAM can force both to the slower settings, or be unstable with XMP or EXPO. Buying a matched pair of the full capacity is safer; if you add, test stability (how to test RAM stability).
  • Capacity before speed. If you are short of memory, faster RAM does not fix it. More does.
  • Close what grows first. A browser with forty tabs or a program with a memory leak can eat what a new stick would add. Check what holds the memory before paying for more.

Short answers

Is 8 GB of RAM enough in 2027?

For a browser and office work, often yes. For modern games with a browser and chat open, it is tight. Measure committed memory and hard faults before deciding.

Is 16 GB enough for gaming?

For most games in 2026 and 2027, yes. If committed memory stays below your RAM and hard faults stay low while you play, more RAM will not make the game faster.

Do I need 32 GB?

When you stream or record while gaming, keep many heavy programs open, edit video or run local AI models (RAM for local AI).

Why is my RAM usage always high?

Windows uses free memory as cache and gives it back when needed. A high percentage alone is not a problem; running out is.
