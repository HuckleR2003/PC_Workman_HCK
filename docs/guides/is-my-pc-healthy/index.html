Is my PC healthy?

Health is not a number you read once. It is whether the machine behaves normally for what it is doing.

By Marcin Firmuga·Published 2026-07-25·7 min read

Someone tells you their PC is "fine". You glance at Task Manager and the CPU is pinned near 100 percent on an empty desktop, doing nothing. Someone else swears theirs is dying, and every reading looks textbook. Neither person is wrong, because health is not a single number you read once. It is whether the machine behaves normally for what it is being asked to do.

A healthy PC is not a PC with low numbers. It is a predictable one. 80 C on the CPU while gaming can be perfectly healthy. The same 80 C, or even 55 C, while the machine sits idle is a warning that something changed. You do not need a benchmark score to tell the difference. You need five minutes and the right five questions.

The five questions

Ask these in order. The first two need no tools at all, and most problems reveal themselves before you reach the fifth.

  1. Does it respond normally? Open a few apps, switch windows, type. Lag, stutter or a freeze is a symptom worth trusting before any number, because it is the thing you actually feel.
  2. Is anything always loading the CPU, RAM or disk? Leave the desktop idle for a minute and look at Task Manager. Something sitting at heavy load while you do nothing is the most common cause of a "slow" machine. If a name looks unfamiliar, check what the process actually is before acting, and if memory is the worry, read what high RAM usage really means first.
  3. Do temperatures match the current work? Hot under load is normal; hot at idle is not. The full picture, per workload, is in our guide on what a normal CPU temperature is.
  4. Does Windows report any hardware, security or storage errors? Windows already tracks this. Open Windows Security, choose Device performance & health, and it reports storage, battery, apps and the Windows Time service. Microsoft's own PC Health Check app and Reliability Monitor (search "reliability") add a timeline of recent faults.
  5. Has behaviour got worse than earlier weeks? This is the question the built-in tools cannot answer, and the most important one. Same workload, but the boot takes longer, the idle temperature crept up, or a new startup entry appeared. A single snapshot looks fine. The trend is where trouble shows up first.

The built-in checks that answer them

You can run the whole check with what ships in Windows. Task Manager answers questions one and two. Windows Security's Device performance & health page and the PC Health Check app answer question four. What none of them do well is question five: they take a photograph, not a history. They can tell you today's storage looks fine. They cannot show how boot time changed since last month unless an earlier measurement was retained for comparison.

Why a health score is a summary, not a diagnosis

One number cannot tell you which part of the machine needs attention. A good headline can help you triage, but only when the tool also shows which readings changed the verdict. CPU load, RAM use, temperatures, throttling and free disk space must stay visible. Treat the score as an index into those checks, never as proof that every component is healthy.

So to answer the question you came with: your PC is healthy when it behaves the way it normally does for the work in front of it. Run the five questions once, and you will know which of them, if any, deserves a closer look. That is the whole check, and it takes about five minutes.
