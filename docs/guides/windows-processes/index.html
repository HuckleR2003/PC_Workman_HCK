What is this process, and is that number normal?

522 Windows processes, each with the CPU and memory it normally uses.

Every other list tells you what a process is. That is rarely the question. You opened Task Manager because something is at eighty per cent, and what you want to know is whether that is a process doing its job or a process in trouble.

So every entry here carries the range it normally sits in. chrome.exe at twenty per cent CPU is a browser with tabs open. csrss.exe at twenty per cent is not, because it normally sits between nought and two.

Of the 522 processes below, 504 are simply safe, 14 are worth a second look depending on where they are running from, and 4 are the kind you investigate. That ratio is the point: almost everything that alarms you in Task Manager is a program doing what it was installed to do.

Where these numbers come from

Because a list of figures with no provenance is worth nothing.

This is the reference library that ships inside PC Workman, a Windows monitor I have been building since 2025. The app uses it to turn a row in a process list into a sentence a person can read, and this page is the same file, rendered.

The CPU and memory ranges are what these programs do on working machines, rounded, not laboratory measurements. They are there to answer "is this number strange", not to be a benchmark. A range is wide where the program is genuinely variable: a browser depends on your tabs and a compressor depends on your file.

The safety reading is about what the program is, not about the file on your disk. A process named svchost.exe is safe. A file named svchost.exe sitting in your Temp folder is not the same thing, and no list can tell those apart for you. The five checks that can take about a minute.
