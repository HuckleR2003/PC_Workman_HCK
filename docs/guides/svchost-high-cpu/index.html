svchost.exe high CPU? Find the service behind it

"Service Host" at the top of Task Manager tells you almost nothing. The name that matters is one click below it.

By Marcin Firmuga·Published 2026-11-28·6 min read
Short answer

svchost.exe is a wrapper that Windows services run in. Since Windows 10 version 1703, on PCs with more than 3.5 GB of RAM, nearly every service gets its own svchost, so dozens of copies are normal. When one uses a lot of CPU, do not fight svchost: find the service inside it by expanding the "Service Host: …" row in Task Manager. The real file is in C:\Windows\System32; a copy anywhere else is a warning sign.

Find the service in a minute

  1. Task Manager, Processes tab. Sort by CPU and expand the "Service Host: …" row at the top. The service running in it is listed underneath.
  2. Details tab. Right-click svchost.exe and choose "Go to service(s)". Task Manager highlights the services that belong to that process.
  3. Command line. tasklist /svc /fi "imagename eq svchost.exe" lists every svchost with its process ID (PID) and the services inside.
  4. Resource Monitor (type resmon): on the CPU tab, tick the svchost and the Services section shows what runs in it.

A spike for a minute or two is usually a service doing its job. High use that stays for hours, or comes back at the same time every day, is worth chasing.

Before you disable any service, check what it does. A disabled service is a change you have to remember and be able to undo; which Windows services you can disable lists the safe ones.

Why there are so many

Windows used to pack many services into a few shared svchost processes. Microsoft changed that in Windows 10 version 1703: on PCs with more than 3.5 GB of RAM, services that used to be grouped now each run in their own svchost. The reasons are reliability (one crashing service does not take others down), security, and making it easier to see which service is using resources. A few services still share a process, for example Windows Firewall with the Base Filtering Engine. On PCs with less memory, services stay grouped and there are fewer copies. Neither number is a fault.

Real or fake

svchost.exe is a popular disguise for malware, because people expect to see many of them. Three quick checks:

  • File location: on the Details tab, right-click and choose "Open file location". The real svchost.exe is in C:\Windows\System32. A copy in AppData, Temp or on the desktop is a serious sign.
  • Name: svhost.exe, scvhost.exe or svch0st.exe are not Windows.
  • Signature: the file's Properties > Digital Signatures should show Microsoft Windows.

More on processes that impersonate system ones is in what is this process.

Short answers

What is svchost.exe?

The Windows Service Host: the process Windows services run in. The service inside does the work.

Why are there so many svchost processes?

Since Windows 10 1703, with more than 3.5 GB of RAM, most services get their own svchost. Dozens of copies are normal.

How do I find which service is using the CPU?

Expand the Service Host row in Task Manager, use "Go to service(s)" on the Details tab, or run tasklist /svc.

Is svchost.exe a virus?

The real one is in C:\Windows\System32 and signed by Microsoft. A copy elsewhere, or a misspelled name, is a warning sign.
