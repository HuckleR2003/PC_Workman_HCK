Windows 11 slow after an update? Prove it before you fix it

"It got slower after the update" is the most common sentence in every Windows forum, and the hardest to check, because nobody wrote down how fast it was before.

By Marcin Firmuga·Published 2026-11-28·8 min read
Short answer

Give it a day or two of normal use first. After an update Windows re-indexes files, optimises apps, scans and updates Store apps, and that work looks exactly like a slow PC. If it is still slow after that, find what the update changed (Windows build, graphics driver, settings), check whether the problem is a known one for that update, compare the same task before and after, and only then roll back the one thing that changed.

Day one: the slowness that goes away

Right after an update, and especially after a new Windows version, the PC is busy with work you did not ask for. None of it is a fault:

  • Search re-indexing: SearchIndexer.exe reads your files again. Disk activity, a fan that does not calm down.
  • App optimisation: .NET recompiles parts of apps in the background (you may see mscorsvw.exe or ngen in Task Manager).
  • A Defender scan of files that changed, and Store app updates that queue up behind the system update.
  • Delivery Optimization and Windows Update finishing downloads inside svchost.exe.

Leave the PC on and plugged in for an hour or two, restart once, and judge it on the second day. A slowdown that is still there then is worth chasing.

What actually changed

An update can change more than Windows itself. Check three things:

  1. The Windows build. Settings > Windows Update > Update history lists what was installed and when. Reliability Monitor (type "reliability" in Start) shows installs, crashes and errors on one timeline, by day.
  2. The graphics driver. Windows Update sometimes installs its own version of the graphics driver over the one from NVIDIA, AMD or Intel. Device Manager > Display adapters > Properties > Driver shows the version and date. A sudden change in games after an update is very often this.
  3. Settings and startup apps. Big updates can switch the power mode, turn features back on or add startup items. Check the power mode in Settings > System > Power and the list in startup apps.

Is it a known problem?

Sometimes the update really is the cause, and the maker says so. Two real examples:

UpdateWhat happenedFix
KB5066835 (October 2025)NVIDIA noted lower performance in some games after this updateNVIDIA hotfix driver, later regular drivers
KB5067036 (28 October 2025, optional)Microsoft confirmed that closing Task Manager with X could leave taskmgr.exe running; copies piled up and used resourcesFixed in KB5068861; until then taskkill /im taskmgr.exe /f

Before you change anything, search the KB number from your Update history together with your GPU or the word "known issue", and look at the Windows release health page. If it is known, the fix is usually a newer update or driver, not a rollback.

Prove it: before and after

"Feels slower" is not something you can fix. Turn it into a number:

  • Boot time: Event Viewer > Applications and Services Logs > Microsoft > Windows > Diagnostics-Performance > Operational, Event 100, records how long each boot took. Compare boots from before the update date with boots after.
  • Games: the same scene, the same settings, average FPS and 1% lows (see frame time and 1% lows).
  • Everyday work: CPU and disk use while idle. If idle CPU is higher than it used to be, something new is running; PC slow but Task Manager looks normal lists the hidden ones.

The weak point of all of these is the "before". Unless you measured before the update, you are comparing with memory.

Roll back the right thing

  1. A driver changed: install the version from the card maker's site, or roll back the driver in Device Manager. Do this before touching Windows.
  2. A monthly update: Settings > Windows Update > Update history > Uninstall updates. Then pause updates for a week, or Windows will install it again tonight.
  3. A new Windows version (feature update): Settings > System > Recovery > Go back. Microsoft says that in most cases this is possible for 10 days, and it removes apps and drivers installed after the upgrade and settings changed since then. Do not delete windows.old in Disk Cleanup before you decide.

Rolling back is a pause, not a fix: security updates come back. Use the time to wait for the corrected update or driver.

Short answers

Why is my PC slow after a Windows update?

Usually temporary work: re-indexing, app optimisation, scans and app updates. If it lasts past a day or two, look at a replaced driver, a known bug or a changed setting.

How long do I have to go back to the previous version?

For a new Windows version, in most cases 10 days (Settings > System > Recovery). A monthly update can be uninstalled from Update history.

Can a Windows update lower FPS in games?

Yes. After KB5066835 NVIDIA noted lower performance in some games and released a hotfix driver.
